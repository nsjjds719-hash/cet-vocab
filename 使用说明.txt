《词间》使用说明（0.1.9）

一、简介

《词间》是一款大学英语四级、六级背单词软件，有安卓手机版和 Windows 电脑版。思路很简单：先学一组新词，再打乱顺序默写，记不牢的词放进生词本，按自己的节奏复习。

- 两本词书：四级 4,951 词，六级 6,148 词，按 2016 年修订版考试大纲补全，两本分别记进度。
- 先学后默写：学习卡上有拼写、词性、中文释义、发音，以及词形变化（如 decided、deciding）和同根词（如 decision、decisive）。学完一组后打乱顺序默写，可选「依义默写」（看中文写英文）或「闻声默写」（听发音写英文）。
- 掌握程度自己定：学习时和答题后都可以标「熟记」或「待复习」，以后随时能改。
- 每天定量：默认每天 35 个新词，可以调整。当天标为待复习的词，从第二天零点起进入复习；漏掉的复习自动顺延。周末可以照常学新词，也可以关掉「周末也读新词」，只复习。
- 五轮学习：第一轮学完整本词书，第二到第五轮重点复习前一轮不熟的词，复习多少由你决定。
- 临考：首页右上角的朱印「考」随时可进。「真题高频」列出四级、六级真题里最常考的各 1,500 个词，觉得不熟点一下就加入生词本；「生词本」里可以浏览、默写，或用「实时测试」随机抽词反复练。
- 离线词典：首页顶部的搜索框支持中英互查，查词形或同根词也能找到原词。
- 外观可调：设置里可换浅色 / 深色主题、按键颜色、背景照片、数字字体、字号等。
- 全程离线：词库和词典都在本机，不用联网，不用注册，学习记录只存在自己的设备上。

二、使用要求

安卓手机
- Android 8.0 或更高版本。
- 发音和闻声默写用手机自带的语音朗读（TTS）。大多数手机自带的语音引擎就能读英文；如果点「聆听」没有声音，请在「设置 → 辅助功能（或系统）→ 文字转语音」里换成支持英语的引擎，或下载英语语音包。

Windows 电脑
- Windows 10 或 Windows 11，64 位（x64）。大多数 Intel / AMD 电脑都是。Windows 11 的 ARM 笔记本（如骁龙处理器）也能用。
  查看方法：设置 → 系统 → 关于 → 系统类型，显示「64 位操作系统，基于 x64 的处理器」即可。
- 需要 Microsoft Edge WebView2 Runtime。Windows 11 和更新过的 Windows 10 一般已自带；没有的话软件会提示，到微软官网搜索「WebView2 Runtime」下载安装即可。
- 发音需要系统里装有英语语音。中文版 Windows 如果点「聆听」提示要安装英语语音，请到「设置 → 时间和语言 → 语音 → 添加语音」，添加「English (United States)」。

三、安装方法

安卓手机（安装包 cijian-0.1.9.apk）
1. 把 apk 文件传到手机上（微信、QQ、数据线都可以）。
2. 点开 apk 安装。第一次安装时，手机会要求允许从该来源（如微信、文件管理）安装应用，点「允许」。
3. 软件没有上架应用商店，手机可能提示「未知来源」或「安全风险」，选「继续安装」或「仍然安装」即可。
4. 升级：以后收到新版本，直接安装新 apk 覆盖旧版，学习记录会保留。请不要先卸载旧版，卸载会删掉学习记录。

Windows 电脑（安装包 Cijian-Windows-x64-0.1.9.zip）
1. 右键压缩包，选「全部解压缩」，解压到一个固定的位置，比如「文档」或 D 盘。不要在压缩包里直接双击运行。
2. 打开解压出来的文件夹，双击 Cijian.exe。可以右键 Cijian.exe →「发送到 → 桌面快捷方式」，以后从桌面打开。
3. 第一次打开时，如果出现蓝色窗口「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。软件没有购买数字签名，这是正常提示，之后不会再出现。
4. 解压出来的其他文件和 web 文件夹都要留着，不要删除或单独移走 Cijian.exe。
5. 升级：删掉旧版文件夹，解压新版即可。学习记录存在系统的用户目录（%LOCALAPPDATA%\Cijian），不在软件文件夹里，所以不会丢。
6. 卸载：删掉软件文件夹。如果连学习记录也要清掉，再删除 %LOCALAPPDATA%\Cijian 文件夹（可以把这个路径粘贴到文件资源管理器的地址栏打开）。

四、使用方法

1. 选词书：首页切换「四级」或「六级」，两本各自记录进度。
2. 每日新词：在首页「今日」卡片里点「新词🔥」开始今天的一组。先逐个看学习卡，可以点「聆听」听发音；看完后进入默写，选依义默写或闻声默写。提交后会显示正确拼写和释义，此时标「熟记」或「待复习」。
3. 每日复习：「今日」卡片会显示到期复习的词数，点「到期复习」完成。首页下方的「已熟记」「待复习」可以查看对应的单词列表。学到一半可以退出，下次打开会接着做。
4. 调整节奏：「今日」卡片里的「每日词量」改每天新词数量，「周末也读新词」开关决定周末学不学新词。
5. 临考冲刺：点首页右上角的朱印「考」进入临考页。
   - 真题高频：按出现频率从高到低列出单词，不熟的点一下加入生词本，不用逐个学习。
   - 生词本：所有标为待复习的词都在这里，可以浏览、点进去看详情，或开始默写。
   - 实时测试：从生词本随机抽 10 个词一轮，循环练习，每轮结束会列出会和不会的词，可以给不会的词加星。实时测试只用来练习，不影响复习进度。
6. 查词：在首页顶部搜索框输入英文或中文，点右侧按钮查询，点结果看详情。离开查词结果时，可以选择把这个词加入生词本。
7. 换外观：点首页右上角朱印左边的设置按钮，可以改主题、颜色、背景照片、字体、字号，以及关闭表情跳动和换页动画。外观设置只影响界面，不影响学习记录。
8. 第一轮学完整本词书后自动进入第二轮。第二轮到第五轮，复习哪些词、复习多少由你决定，也可以自己结束当前这一轮。

五、注意事项

- 手机和电脑的学习记录是分开的，互不同步。
- 学习记录只存在本机。换手机或重装系统前，记录不会自动迁移。
- 每天的分界是你设备上的当地时间零点。
